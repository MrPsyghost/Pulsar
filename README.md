# Pulsar

A notes taking assistant bot. It's functions include:

* Checking or Verifying Notes
* Deciphering shorthands/symbols in user uploaded notes for user personalization
* Completing incomplete notes
* Suggesting better note taking techniques
* Explaining given notes

## Usage

Pulsar can be launched by exectuing the app.py python program file in the given zip folder.  
To Check/Verify notes, upload notes either as plain text in the text box or uploading images of your notes using the add button.
Shorthands/Symbols are automatically deciphered and better note taking techniques are also suggested accordingly.

Note: Images must be uploaded in correct order.

___

To explain notes/complete notes, Pulsar must be explicitly instructed.  
The default function of Pulsar is to check/verify notes.  
Pulsar only remembers the most recent notes and instructions for storage omptimisation but the shorthands of all notes are permanently stored, categorised under subjects and topics.  
Note:

1. For best results it is best to mention the subject and topic in the notes images.
2. Pulsar must be provided with a stable internet connection.
