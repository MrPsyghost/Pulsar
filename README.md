# Pulsar

Pulsar is an AI-powered student note-taking assistant designed to help students review, improve, and understand their notes.

## Features

- **Check and verify notes** for factual, conceptual, mathematical, scientific, grammatical, and logical errors.
- **Decipher meaningful shorthands and symbols** used in notes to provide a more personalized experience.
- **Complete incomplete notes** when explicitly instructed.
- **Suggest improved note-taking techniques** where appropriate.
- **Explain notes and concepts** when requested.

## Usage

Pulsar can be launched by running the `app.py` file included in the project folder or by using the installer to install Pulsar in your computer and then running Pulsar.exe.

To check or verify notes, enter them directly into the text box or upload images of handwritten or typed notes using the add button.

Pulsar automatically identifies and deciphers meaningful shorthands and symbols used in the notes. These can be remembered and used as contextual information in future note processing.

> **Note:** When uploading multiple images, ensure they are uploaded in the correct order.

---

The default function of Pulsar is to **check and verify notes**. To perform other tasks, such as explaining or completing notes, provide an explicit instruction.

For storage optimisation, Pulsar only retains the most recent notes and instructions. However, deciphered shorthands can be stored locally and organised according to their relevant subjects and topics to improve personalization.

### Notes

1. For the best results, clearly mention the **subject** and **topic** in your notes or accompanying input.
2. A stable internet connection is required for AI processing.
3. Your API key is stored locally on your device.
4. Notes and uploaded images are processed for the requested task and are not permanently stored by the application.
